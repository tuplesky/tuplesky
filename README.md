# TupleSky

A proposed Rust multi-region coordination service with SwiftPaxos, postcard over QUIC, Kine integration, and independently scalable non-voting read/watch replicas.

Start with the [design review index](docs/design/README.md).

This branch includes the original v0.5 design and v1.2 implementation plan, the v0.6/v1.3 revision supplements, and the SwiftPaxos upstream-issue amendment. Read the baseline and supplements together using the index's precedence rules. These are proposed engineering work, not implemented or verified service features.
