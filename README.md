# TupleSky

A proposed Rust multi-region coordination service with SwiftPaxos, postcard over QUIC, Kine integration, and independently scalable non-voting read/watch replicas.

Start with the [design review index](docs/design/README.md).

This branch contains the v0.6 design and v1.3 plan supplements, plus a SwiftPaxos upstream-issue amendment. These are proposed engineering work, not implemented or verified features. The original v0.5 design and v1.2 plan baselines are still required and are not yet included; the index records that dependency explicitly.
